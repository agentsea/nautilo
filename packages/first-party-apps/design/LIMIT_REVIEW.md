# Design limit review — D575

This is a source-grounded review of the Design limits removed for D575 and of
remaining limits that need an owner decision. It is not a replacement baseline
or an approval of the remaining limits.

## Evidence and method

- The supplied initial check at `/tmp/d575-limits-check.log` found nine removed
  Design observations and stale generated reports. The supplied shrink log at
  `/tmp/d575-limit-shrink.log` records `4126 -> 4117` frozen legacy rows.
- Each retired fingerprint below is from
  `git show HEAD:packages/limit-invariants/baseline/limit-inventory.jsonl`.
  Locators and source lines therefore identify the exact pre-removal
  observation, even when the current source has moved.
- I traced the declaration to its consumer and the user-visible result in the
  pre-removal source and tests. Existing boundary tests are evidence of prior
  behaviour, not authority for a number.
- `packages/limit-invariants/generated/limit-scout.jsonl` says the scout is a
  mechanical source navigator. Its coverage cannot determine legitimacy,
  runtime-only values, re-export chains, generated programs without a numeric
  interpolation, or languages/binaries outside TypeScript/JavaScript, JSON,
  YAML, shell, and TOML. The current investigation map has one Design
  policy-family lead: `MAX_SEMANTIC_CONFLICTS` and server
  `MAX_STALE_SEMANTIC_CONFLICTS`; it is a name/value lead only, not shared
  authority.

## PNG and host completion follow-up

The canonical SVG-to-PNG host uses Sharp without its default input-pixel ceiling
(`limitInputPixels: false`). It adds no app-local byte/pixel admission ceiling,
truncation, raster downsampling, or font substitution. The codec's resource and
format failures remain visible. Resource-free XML validation disallows external
fetches, styles, embedded images, executable content, and cyclic references;
numeric arity, finite coordinates, RGB channels and opacity are format checks.
Text bounds use exact bundled glyph ink plus transformed stroke extent; the
miter extent derives from SVG's default limit of four half-stroke widths
([SVG 1.1 painting](https://www.w3.org/TR/SVG11/painting.html#StrokeMiterlimitProperty)),
not a cap on artwork size. These are manual semantic findings; the detector did
not create independent policy observations for each format check.

The runner's existing 10,000 ms wall-clock default remains **unresolved temporary
debt**, with no operational measurements or caller authority establishing it.
Its constant and current timer consumer have explicit reviewed `defer_named`
rows; the old timer consumer was replaced, never absorbed into frozen debt.
Do not interpret a green inventory gate as acceptance of this duration. A future
policy must derive it from applicable authority or replace it with a coherent
caller cancellation/continuation contract. The 50 MiB RPC wire budget and other
unchanged runtime limits likewise retain their existing review/debt status.

D575 preserves truthful outcomes at this boundary: expiry kills worker code and
rejects buffered late RPCs, but an admitted host write settles and its confirmed
or partial receipt survives. A confirmed single matching SVG/PNG receipt recovers
the host conversion; a partial write retains bytes and exposes its path,
stateChanged, and retrySafe=false. No canonical success is inferred from elapsed
time, and there is no safe automatic replay claim. Runner, route, registration,
binary-failure and raster-host regression tests provide executable evidence.

## Referenced images, fonts and recovery follow-up

D575 now supplies the narrow verified-first-party raster bridge needed by Design;
this does not claim the full D385 media platform. PNG/JPEG/WebP bytes stay in
canonical Workspace custody and in transient host/browser decode buffers. The
native scene stores an artifact UUID and SHA-256 only. Browser readback and server
export both verify the pinned bytes. SVG/PNG delivery resolves only referenced
images in the chosen export scope; missing, changed, animated, and inaccessible
assets fail explicitly. No new pixel ceiling, downsampling, or inline native
raster storage was added. Sharp's default pixel ceiling remains disabled.

The font generator's 120-character slices are lossless source formatting, not
font or document truncation: every contiguous slice is emitted and joined, and
the generator checks complete canonical face hashes. Its exact primary locator
`packages/first-party-apps/design/scripts/generate-bundled-fonts.ts#chunks:call:slice:2296341a3952:1`
and fingerprint `b2b7f9c5dd3d284b1a429ff0af82a3c2cce79b285b9c9b681cdeb88ed9a79911`
are reviewed as `lossless_boundary / retain` with generator/glyph evidence.
Raster signature/chunk lengths are format structure; two tracked touch points
provide the midpoint and separation for pinch navigation, without limiting
artwork or truncating a document selection.

Artifact-state PUT now reuses the existing Artifact-save HTTP body setting,
removing an accidental Fastify 1 MiB recovery boundary. The changed consumer is
reviewed as **temporary debt**, not authority for 64 MiB. Tests persist an exact
recovery envelope above 1 MiB and retain write authorization. The existing 50 MiB
document boundary can still expand beyond the 64 MiB JSON envelope after escaping.
The named shared recovery follow-up should persist exact recovery bytes through
artifact storage and keep identity/version metadata in generic state. Until then,
a failed recovery write stays visible; the editor retains its draft and Save Copy.

Other inspected shared boundaries remain unresolved: the source editor rejects
the whole generated 3,190,590-byte font module before range-reading because of its
262,144-byte file check; the canonical multipart uploader has a 100 MiB default;
and browser/server raster decode retains multiple complete encoded/decoded copies.
Do not split fonts to evade the source limit or infer a safe image cap from a
library default. Source range streaming, upload/decode admission and isolation
need shared designs based on actual authority and measurements. `unlimited:false`
retains codec failure behavior, not a qualified product memory policy. Unchanged
50 MiB tool wire, 64 RPC-count and diagnostic truncation observations remain debt.

Final scoped inventory: 4,594 observations, 486 reviewed decisions, 4,108 frozen
legacy observations. No new frozen debt was admitted. A green inventory does not
approve the named shared transport, deadline, source or decoder limitations.
Representative small/medium/large measurements are recorded separately in
`design-editor-audit-2026-09-05/d575-performance-evidence.md`; samples are evidence,
never admission thresholds. Complete paginated inspection is the dominant cost
in the measured 1,001-node scene (2.86 seconds across 16 pages).
