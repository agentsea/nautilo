# Mac Desktop App

SwiftUI application that absorbs the relay daemon and adds desktop presence.

## What will live here

- Menu bar icon, global hotkey, screen awareness.
- Wake word and voice mode.
- Local execution: file access, AppleScript, Wake-on-LAN.
- Local smart-home relay (from the daemon).
- Desktop-agent profile when connected to cloud.

## Build system

Xcode / Swift Package Manager. Standalone project.
