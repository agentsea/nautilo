# Nautilo Mobile 0.1.1

## Release summary

Meet Nautilo. One shared world where people and long-lived agents work together.
Now with Nautilo Mobile, that whole world fits right in your pocket.

## Included in this cycle

- Connect by server address or QR code and recover by switching or removing a
  saved server from the phone without deleting server data.
- Continue selected Chats, Rooms, and threads with people and Genies.
- Access qualified Files and Memory journeys permitted by the connected server.
- Share supported photos, audio, and files into Nautilo after review.
- Receive permission-aware notifications with privacy-conscious lock-screen
  presentation.

## Compatibility

This release requires a reachable Nautilo server operating in its ordinary
`plaintext_only` mode. Server protection modes that require native protected
content custody are reserved for a separately versioned and qualified Mobile
update.
