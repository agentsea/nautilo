# Nautilo Mobile 0.2.0

## Release summary

Read documents, zoom into images, watch videos, and take your files with you.

## Included in this candidate

- Read Writer and static HTML documents, including embedded PNG, JPEG and GIF
  images, without converting the original file.
- Inspect images full screen with pinch, pan, double-tap and zoom controls.
- Play supported videos with native playback and full-screen controls.
- Save original files from Files and retained conversation attachments, even
  when Mobile cannot preview their format.
- Save supported images and videos to Photos on iPhone or Gallery on Android.
- Share original files through the iPhone share sheet. On Android, save the
  file first, then share it from Android Files.
- Follow streaming replies with improved Markdown layout, including lists and
  tables, and edit your sent messages without disturbing the composer draft.
- Keep message-edit actions above the keyboard while scrolling long drafts
  and reviewing conflicting edits.
- Browse workspace Files in one list without the All files / Shared with me
  tabs, while retaining search, conversation filtering and paired-computer
  browsing. Existing sharing actions and permissions remain in place.
- Use matching compact Save and Edit actions in the file viewer.

## Compatibility and known boundaries

Requires a reachable Nautilo server in `plaintext_only` mode. Server-owned
file and Room permissions remain authoritative; this release does not change
encryption admission or server storage/history.

The document reader is read-only and does not execute embedded scripts.
Separately linked images, stylesheets and other resources are not loaded;
unavailable resources are disclosed and the original remains available to save.
Videos download before playback; supported codecs depend on the device.
Saved copies are independent of later server edits and access changes.

## Tester notes

On real iPhone and Android devices, check document reading, image gestures,
video play/pause/seek/full screen, Save file, Photos/Gallery and iPhone Share.
Try cancellation, denied permissions, offline recovery and returning to the
same conversation. Check message times and workspace sharing from 0.1.2.
For the refreshed tester candidate, also check streaming replies, Markdown
lists/tables, and message editing with the keyboard open. Try a long draft,
Cancel, a failed save and a conflicting edit from another device; your draft
should remain intact, with explicit review required before replacing a newer
message.
For the Files refresh, check the unified list, search, conversation filtering,
paired-computer browsing, file opening, Save original and Edit. Check both
light and dark presentation on real devices, especially Android, where the
feature PR did not claim visual qualification.

Please also test computer pairing with the current relay and voice input.
Physical-device, third-party file-provider, full-storage and legacy Android
coverage remains open; those are not claimed passes by this release note.

## Native changes and recovery baseline

This cycle adds expo-video ~57.0.2, react-native-webview 13.16.1 and the local
native media export module/plugin. Photo export uses add-only permission on
iOS, app-owned MediaStore writes on Android 10+, and legacy write permission
limited to Android 9 and earlier. It does not request broad library read
access for export. Server permissions and encryption admission are unchanged.

The previous tester baseline is 0.1.2: iOS build 31 and Android code 37, from
`29828af2b85f8bb2a48368cec231b52bf3c1308d`. Rebuilding any recovery candidate
requires fresh native counters; a previous version code must not be reused.
