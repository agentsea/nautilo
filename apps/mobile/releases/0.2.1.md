# Nautilo Mobile 0.2.1

## Release summary

A maintenance tester release following [0.2.0](0.2.0.md). It retains document
reading, image and video viewing, original-file saving, workspace Files and
conversation features from that release.

## Compatibility and testing

Requires a reachable Nautilo server in `plaintext_only` mode. The supported
server modes, native permissions and document/media boundaries are unchanged
by this version update.

Check sign-in, Rooms, streaming replies, message editing, Files, original-file
saving, document/media viewing, computer pairing and voice input on iPhone and
Android. Store delivery is verified below. Physical-device smoke tests and
Google Play tester enrollment were not verified by the release qualification.

## Release identity

App Store Connect reports 0.2.0 as released and no longer accepts new builds
for that version. This patch version starts the next tester candidate.

The 2026-09-13 qualification verified Android code 42 submitted to the completed
Google Play internal track and iOS build 37 processed and assigned to the
existing Nautilo RC TestFlight group. The ledger records each exact product
source, native builder commit, build and submission identity. This is tester
distribution, not a public 0.2.1 rollout. Earlier release and build records remain
intact.
