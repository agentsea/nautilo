# Nautilo Mobile 0.1.2

## Release summary

Message times and shared workspaces, now on Mobile.

## Included in this candidate

- See when messages were sent. Tap a time for the full date and timezone.
- Add a writable file to another person's workspace without sending a chat
  message or making a separate copy.
- Find files people have shared with you under Files → Shared with me.
- Retry failed sharing deliveries without repeating successful ones.

## Compatibility

Requires a reachable Nautilo server operating in `plaintext_only` mode, with
the existing workspace-sharing APIs. File access remains controlled by the
connected server. This candidate does not change encryption admission.

## Tester notes

Please check message times, file sharing, and Shared with me on real phones.
Try recipient search with the keyboard open and retry after a connection
failure. Live-instance computer pairing will be qualified using these tester
builds; pairing and the reported Android talk-button blink are not claimed as
fixed or qualified by this release note.
