# Documentation

Nautilo's public documentation has two canonical homes:

- [Nautilo.ai documentation](https://nautilo.ai/docs) for users, operators,
  contributors, and architectural concepts;
- this repository for documentation that must stay versioned with the source,
  build, packaging, and release contracts.

No private repository is required to understand, build, test, contribute to,
operate, package, or release the public source tree.
